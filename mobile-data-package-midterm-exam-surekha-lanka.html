Java Midterm Practical Exam

Project: Mobile Data Package Billing System

Project scenario: A mobile-phone company needs a simple Java console program that displays a customer's profile, monthly charges, and final payment amount.

CourseIntroduction to Java Programming
Duration1 Hour 30 Minutes
Total Marks50 Marks

Student Information

Step 1 of 4Complete each section before continuing

Step 1: Customer Profile — 15 Marks

Write only the Java statements for this part. Do not write the complete program yet.

Instruction
  • Declare customerName as a String with value "Surekha_Lanka".
  • Declare phoneNumber as a String with value "0812345678".
  • Declare packageType as a char with value 'P'.
  • Declare accountActive as a boolean with value true.
  • Print the heading Customer Profile and all customer details with labels.

Step 2: Monthly Charges — 15 Marks

Write only the declarations, calculation, and output statements for the monthly charges.

Instruction
  • Declare monthlyPackageFee as a double with value 299.00.
  • Declare extraDataCharge as a double with value 45.50.
  • Declare serviceFee as a double with value 10.00.
  • Calculate totalBill using: monthlyPackageFee + extraDataCharge + serviceFee.
  • Print heading Monthly Charges and display all charges and the total bill.

Step 3: Payment Summary — 10 Marks

Use the variables from earlier steps. Write only the final payment output statements.

Instruction
  • Print the heading Payment Summary.
  • Display the customer name and totalBill with suitable labels.
  • Print a blank line.
  • End with: Thank you, "Surekha_Lanka"!.
  • Use an escape sequence to display quotation marks around the customer name.

    How it works

    Gate 1: Q = NOR(R, Q)

    Gate 2: Q = NOR(S, Q)

    A NOR gate outputs 1 only when every input is 0. Each gate output is fed back into the other gate's input, so once an output settles it keeps itself in place — that feedback loop is the memory.

    Worked example (the diagram)

    R = 0 (top switch OFF), S = 1 (bottom switch ON)

    Gate 2: Q = NOR(1, Q) = 0

    Gate 1: Q = NOR(0, 0) = 1

    Result: Q = 1 (top bulb ON), Q = 0 (bottom bulb OFF). Returning S to 0 keeps Q = 1 — the latch has stored the bit.

    Activity 2: Concept Check

    1. In a NOR-based SR latch, when does a NOR gate output a 1?

    2. The latch is currently in the Set state (Q = 1). What happens when S and R are both returned to 0?

    3. Why is S = R = 1 called the invalid or forbidden condition?

    4. What gives the SR latch its ability to remember one bit?

    5. Starting from Q = 1, the inputs are set to S = 0 and R = 1. What is Q?

Part 1 — Complete the DP Table

Row i considers only the first i+1 items. Column j is the bag capacity used so far. Rule: dp[i][j] = dp[i-1][j] if the item's weight is more than j, otherwise the larger of dp[i-1][j] (leave the item out) and value + dp[i-1][j-weight] (take the item). Treat row i-1 as all zeros when i = 0.

# Interactive Tri-State Bus

Static HTML activity prepared for GitHub Pages.

## GitHub Pages

This project is ready to publish from the repository root. GitHub Pages will use `index.html` as the site entry point.

After pushing to GitHub:

1. Open the repository on GitHub.
2. Go to `Settings` > `Pages`.
3. Set `Source` to `Deploy from a branch`.
4. Select the `main` branch and `/root` folder.
5. Save.

The site will publish at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/
```

Student Activity: Exploring a Tri-State Bus

Use the simulator to investigate how a decoder enables one tri-state buffer and allows one input to control a shared bus.

Student Information

Learning Outcomes

Explain the purpose of the high-impedance (Z) state.
Determine which input is selected by S1 and S0.
Explain how tri-state buffers prevent bus contention.
Instructions: Change the input values and control signals. Observe the highlighted decoder output, enabled buffer, selected input, and resulting bus value.

Activity 2: Concept Check

1. What does the high-impedance state Z mean?

2. When E = 1 and S1S0 = 10, which input drives the bus?

3. Why should only one tri-state buffer be enabled at a time?

4. With A0 = 1, B0 = 0, C0 = 1, and D0 = 0, what is the bus value when E = 1 and S1S0 = 01?

5. What is the bus value when E = 0?

Obstacle Runner — Java Movement Game

Write real Java code and run it right here in your browser. Your program's output drives the Game Screen: print game commands such as @POSITION 7 and the page moves a runner along a track.

There is one plain runner marker — no character to choose — so the focus stays on the logic: moving forward and backward, tracking barriers, and deciding when to jump. This page uses Java 8. Avoid newer features such as var, records, text blocks and switch ->. The first run downloads Java into your browser and can take up to a minute.

Game command reference

Print a line that starts with @. It goes to the Game Screen, not the console. Easiest way: add the show() method below to your Main class.


static void show(String command) {
    System.out.println("@" + command);
}
// usage: show("POSITION " + position);




Print thisWhat happens


@PLAYER AlexShows the player name


@LIVES 3Updates the lives counter


@SCORE 50Updates the score


@POSITION 7Moves the runner to that spot on the track (higher = forward, lower = backward)


@TRACKLENGTH 20Sets how far the finish line is (default 20). Print this once near the start.


@BARRIER 10Places a barrier marker on the track. Send one line per barrier.


@JUMPPlays the jump animation


@HITFlashes the runner — use this when your checkBarrier() finds a collision


@EVENT Nice dodge!Adds a message to the event log


@RESULT WIN Reached the finish lineShows the final WIN or LOSE screen

Problem 1 — Number of Ways to Make Change

Coins (C): 1, 2, 3 Change (N): 5
Each row adds one more coin to the set you may use. A cell is the number of different ways to make that amount using only the coins up to that row. Rule: ways[row][n] = ways[row-1][n] + ways[row][n-coin] (only add the second term when n ≥ coin), and the first row (using only the 1-coin) is always 1 for every amount.

Problem 2 — Minimum Number of Coins

Coins (C): 1, 5, 6 Change (N): 11
Each row adds one more coin to the set you may use. A cell is the smallest number of coins needed to make that amount using only the coins up to that row. Rule: min[row][n] = smaller of ( min[row-1][n] , 1 + min[row][n-coin] ) (only consider the second option when n ≥ coin), and the first row (using only the 1-coin) always needs exactly n coins.
